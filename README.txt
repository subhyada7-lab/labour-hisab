# Labour Hisab Advanced
Hindi + English PWA for construction labour attendance, daily wages, overtime, advance/payment, reports and backup.

## What is included
- Modern Labour Hisab dashboard
- Hindi / English switch
- Labour / Mistri list
- Daily attendance: P / H / A / OT
- Daily rate and OT rate
- Advance / payment history
- Automatic earned / paid / balance calculation
- CSV report and Print / Save PDF
- JSON backup / restore
- Installable PWA
- Professional construction logo

## Online installation
Upload ALL files in this folder to any HTTPS static hosting service (for example GitHub Pages or another static host). Open the HTTPS website in Chrome on Android. Tap the Install App button, or Chrome menu -> Add to Home screen.

## Play Store
This folder is a web/PWA build. Google Play publishing normally needs an Android package (AAB) and a Play Console developer account. The same HTTPS PWA can be wrapped into an Android app with a Trusted Web Activity / Android wrapper, then signed and uploaded as an AAB.
