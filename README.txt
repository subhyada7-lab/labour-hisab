# Labour Hisab - Construction Management System

Labour Hisab ek modern Progressive Web Application (PWA) hai jo construction sites par mazdooron ki hajari aur hisab-kitab ko aasan banata hai.

## Key Features
- **Dashboard UI**: Comprehensive project overview & daily summary.
- **Bilingual Support**: Hindi aur English language toggle.
- **Attendance Tracker**: Present, Half Day, Absent, aur Overtime logging.
- **Financial Tracker**: Daily rate, advance payment, aur balance calculation.
- **Reports & Backup**: PDF/CSV export aur JSON backup support.
- **PWA Ready**: Mobile par install karne aur offline chalane ke liye suitable.
